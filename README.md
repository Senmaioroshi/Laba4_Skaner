# Лабораторная работа №4 — Skaner

## Описание

**Skaner** — Android-приложение для сканирования текста.  
Приложение позволяет выбрать изображение и распознать текст с него.

## Функции

- выбор изображения;
- сканирование текста;
- распознавание текста с картинки;
- отображение результата на экране.

## Технологии

- Java
- Android SDK
- XML
- OCR
- Text Recognition

## Разрешение

```xml
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
```
